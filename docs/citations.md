# 文献引用

MarkText 可以使用你自己的本地 BibTeX/BibLaTeX 文献库。通过“格式 → 文献引用设置”选择 `.bib` 文件、样式和参考文献标题，也可以直接编辑文档顶部的 YAML：

```markdown
---
bibliography: ./references.bib
csl: ieee
reference-section-title: 参考文献
---

已有研究提出这一方法 [@vaswani2017]。
多篇引用 [@vaswani2017; @devlin2019]。
指定页码 [@devlin2019, pp. 3–5]。
```

引用键对应 `.bib` 条目的名称，例如 `@article{vaswani2017, ...}` 中的 `vaswani2017`。引用键区分大小写。

EndNote 导出的文件也可以直接使用：扩展名可以是 `.txt`，内容必须是 BibTeX/BibLaTeX。部分导出记录只有 `@misc{`，下一行直接开始 `author = ...`，没有引用键；MarkText 会跳过这些条目并提示数量，其余文献正常加载。被跳过的条目不参与补全、引用排版和参考文献列表，原始文献库不会被改写。需要引用这些条目时，先在文献库中为它们补上引用键，再点击“刷新文献库”。已有引用键保持不变，重复键和其他格式错误仍会提示。

## 选择自己的文献库

相对路径以 Markdown 文件所在目录为基准，不受当前打开的项目目录影响。也支持绝对路径及多个库：

```yaml
bibliography:
  - ./references/papers.bib
  - D:/Research/books.bib
```

尚未保存的文档需要先保存才能使用相对路径。选择文件的界面会为已保存文档优先生成相对路径。

内置样式是 `ieee`（数字式，默认）和 `apa`（作者年份式）。也可以指定本地独立的文内引用 CSL 样式：

```yaml
csl: ./journal.csl
```

`ieee`、`apa` 是 MarkText 的内置别名；在外部 Pandoc 中处理同一文稿时，需提供对应 CSL 文件。首版不支持脚注型 CSL 或依赖其他样式的 CSL 文件。

## 引用键和标题补全

普通编辑模式与源码模式都支持：

- 输入 `[@` 打开候选。
- 输入引用键片段，例如 `[@vasw`。
- 输入论文标题片段，例如 `[@Attention Is All`，也支持中文标题。
- 候选显示标题、引用键、作者和年份；方向键选择，Enter/Tab 确认，Esc 关闭，也可以用鼠标选择。

无论按标题还是引用键选择，插入的都是 `[@vaswani2017]`。多篇引用中，输入 `; @` 可以继续选择下一篇。补全不会覆盖已有页码或其他引用。

## 编辑和显示

普通编辑模式下，引用显示为所选样式的编号或作者年份。点击引用或将光标移入其范围，恢复 `[@…]` 供编辑；移开光标后恢复排版显示。按住 Ctrl（macOS 上为 Command）点击引用可跳到已保存列表中的条目。

源码模式始终保留 Markdown 原始语法。保存的 `.md` 保留引用键和配置，不包含自动生成的编号或列表正文。

## 参考文献列表的刷新

文末参考文献为只读、可折叠的列表：

- 打开已保存的文档时，按该文稿生成初始列表。
- 编辑引用时，文内显示可以更新，末尾列表保持不变，并提示“保存后更新参考文献”。
- **只有保存成功后，末尾列表才刷新**；取消或保存失败不会刷新。自动保存、另存为也遵循成功保存后刷新。
- 新建且未保存的文档，要在首次保存成功后才生成列表。
- “刷新文献库”更新搜索与文内显示使用的数据，末尾列表仍等到保存成功后刷新。

文献解析和 CSL 排版在后台执行。普通正文改动不会重复运行 CSL；光标进出引用只切换显示，不重排文献。

## 导出

HTML、PDF 和打印按当前文稿生成引用及参考文献，使用同一排版结果。导出前核对本地文献库是否改变；导出处理不会刷新编辑器内保存时生成的列表。

缺少文献库、配置错误、重复引用键、未知引用键或无效 CSL 时会显示提示。未解决的错误会阻止文献导出。

首版支持括号式单篇、多篇引用和 `p.`/`pp.` 页码，不支持裸 `@key`、`[-@key]`、`nocite`、任意位置列表及 LaTeX 的 `\cite{}`、`.bst`。代码、公式、链接目标和 HTML 属性中的类似文字不会作为引用处理。
