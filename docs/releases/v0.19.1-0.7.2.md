## 0.19.1 个人维护版 · 第 0.7.2 修订版

- 修复跨电脑下载 Gist 设置时，使用另一台电脑的用户目录创建截图文件夹而报 `EPERM` 的问题。
- 上传时不再包含图片、截图存储目录的绝对路径；下载时也会忽略旧同步文件中的这些路径，保留本机设置。
- 相对图片路径、其他偏好设置和快捷键继续同步；本地同步备份保留原始路径，便于恢复。
- 增加 Windows、macOS/Linux、网络共享路径及相对图片路径的轻量回归检查，并加入自动发布检查流程。

如果此前失败的同步已改写本机图片目录，请在图片设置中重新选择本机目录。本版本会阻止远端绝对路径再次覆盖本机设置，但不会搬移原有图片。

本地验证：设置同步轻量回归检查、版本一致性及补丁空白检查通过。完整单元测试、类型、静态、许可检查及多平台构建由 GitHub Actions 发布流程执行，通过后自动发布安装包。
