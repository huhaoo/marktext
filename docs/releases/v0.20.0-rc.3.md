## 文献引用与补全

- 关联自己的本地 BibTeX/BibLaTeX `.bib` 文献库。
- 在普通编辑和源码模式中，按引用键或中英文标题搜索、补全引用。
- 支持 `[@key]`、多篇引用及页码；内置 IEEE、APA，并支持本地独立 CSL 文内引用样式。
- 编辑引用时恢复原始语法，离开后显示引用编号或作者年份。
- 文末参考文献列表只在保存成功后刷新，可折叠、可跳转；后台执行文献解析和排版。
- HTML、PDF 和打印使用当前文稿的引用结果。

从 **格式 → 文献引用设置** 选择 `.bib` 文件，也可使用：

```yaml
---
bibliography: ./references.bib
csl: ieee
reference-section-title: 参考文献
---
```

正文示例：`已有研究支持这一结论 [@vaswani2017]。`

[完整使用说明](https://github.com/huhaoo/marktext/blob/master/docs/citations.md)

## 自动发布

推送版本标签后先检查版本一致性、单元测试、类型、静态检查及许可，再构建五个平台/架构的安装包并发布 GitHub Release。支持从 Actions 页面按已有标签重跑。

Windows 用户可选择对应架构的 `setup.exe` 安装包；`zip` 为免安装包。文件名包含平台、架构和版本标签。
