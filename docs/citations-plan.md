# MarkText 文献引用方案与实施记录

日期：2026-10-11。用户已批准实施。实现与使用说明见 `docs/citations.md`。

后续确认的行为已纳入实现：引用仅在编辑时恢复 `[@…]`；引用键与标题均可补全；首次打开已保存文稿时生成列表，之后仅在保存成功后刷新文末参考文献。解析及 CSL 排版在后台执行，普通正文编辑复用排版缓存。导出处理当前文稿，不刷新编辑器中的已保存列表。

## 目标与结论

实现 `.bib` 文献库、引用键、自动文内引用和参考文献列表，并让编辑器显示、HTML 导出、PDF 导出及打印保持一致。

推荐采用 **Pandoc 风格的 Markdown 引用语法 + 内置 BibTeX 解析器 + CSL 排版引擎**。使用时无需安装 LaTeX 或 Pandoc。这是类似 LaTeX 的文献引用工作流，不包含 LaTeX 宏系统、`.bst` 样式或公式/图片的交叉引用。

## 已核实的项目现状

- 桌面版 `packages/desktop/electron.vite.config.ts` 将 `muya` 指向 `packages/muyajs`；`packages/muya` 是另一套编辑器，当前桌面版未接入。
- `packages/muyajs` 已支持 front matter、引用式链接、脚注和数学公式，但未发现文献引用处理。
- `packages/desktop/src/main/utils/pandoc.ts` 及文件菜单中的调用用于外部格式导入。
- 当前 HTML/PDF/打印共用 `editor.vue` → `exportStyledHTML()` → `packages/muyajs/lib/utils/exportHtml.js`。PDF 最后由 Electron 打印生成。
- 渲染进程通过 preload/IPC 访问本地文件；引用库加载遵循同一边界。
- 工作区初始无未提交修改；未发现适用的 `AGENTS.md`。

## 路线比较

| 路线 | 编辑时显示 | 安装要求 | 与现有导出衔接 | 判断 |
| --- | --- | --- | --- | --- |
| 只在导出时调用 Pandoc `--citeproc` | 需另建显示链路 | 用户安装 Pandoc | 需处理公式、图表和主题差异 | 不作为首选 |
| 内置解析及 CSL 排版 | 编辑和导出共用结果 | 无外部程序 | 保留现有导出流程 | 推荐 |
| 自行解析 BibTeX、手写排版规则 | 可以实现 | 无外部程序 | 可接入 | 作者姓名、排序、消歧维护成本高 |

## 首版用户体验

1. 在“文献引用设置”中选择一个或多个本地 `.bib` 文件、样式和列表标题，保存到文档 YAML front matter；也可直接编辑 YAML。
2. 输入 `[@` 后出现候选文献，支持按引用键或论文标题补全，也可按作者或年份搜索。候选显示标题、引用键、作者和年份；选中后插入对应的引用键。普通编辑模式和源码模式都提供补全。
3. 非编辑状态显示排版后的引用；光标进入引用范围时显示原始语法供编辑。悬停显示文献信息，点击跳到参考文献条目。
4. 文末显示只读、可折叠的自动参考文献列表，仅列出被引用的文献。保存成功后更新列表；编辑过程中只更新文内引用并提示保存后刷新列表。
5. 源码模式和保存的 `.md` 保留引用键和配置，不写入生成的编号或参考文献正文。
6. HTML、PDF 和打印包含同一份排版结果。

推荐示例（`paper.md` 与 `references.bib` 在同一目录）：

```markdown
---
bibliography: references.bib
csl: ieee
reference-section-title: 参考文献
---

# 研究背景

已有研究提出了这一方法 [@vaswani2017]。
多个研究支持这一结论 [@vaswani2017; @devlin2019]。
具体论述见 [@devlin2019, p. 3]。
```

`ieee` 为 MarkText 内置样式别名；用外部 Pandoc 处理时，需要对应的 CSL 文件。选择自定义样式则记录本地 `.csl` 路径。

## 首版范围与兼容规则

- `.bib` 使用成熟库读取 BibTeX/BibLaTeX 常见条目，保留原引用键及大小写；重点验证 Zotero/Better BibTeX 常见输出、中文及 LaTeX 字符转义。
- 支持 `bibliography` 字符串或数组；相对路径以当前 Markdown 所在目录为基准。未保存文档的相对路径提示先保存，选择绝对路径仍可使用。
- 支持括号式单篇、多篇引用及 `p.`/`pp.` 页码。明确作为 Pandoc 引用语法的一个子集，不宣称完整兼容。
- 内置 IEEE 数字式和 APA 作者年份式；默认 IEEE。用户可加载独立的本地 CSL 文内引用样式。依赖样式及脚注型 CSL 首版给出明确的暂不支持提示。
- IEEE 编号按首次出现顺序；同一文献重复引用复用编号。APA 排序、作者缩写和同作者同年消歧由引擎决定。
- 代码块、行内代码、公式、链接目标、HTML 属性和转义文本不解析为文献引用；脚注正文、表格正文中的引用纳入文档顺序。
- 只在存在有效 `bibliography` 配置时启用；普通 Markdown 的 `@` 文本及原有脚注/引用式链接继续按现有规则处理。
- 自动列表位于正文末尾，不进入编辑器文档状态、撤销历史、字数统计或保存结果。首版不支持任意位置放置列表。
- 引用库被外部修改后，提供“刷新文献库”；窗口重新获得焦点时检查更新；每次导出前重新核对文件。刷新文献库更新候选及文内引用，末尾列表仍等待成功保存。首版不增加长期文件监听器。
- 无效引用键在编辑器中保留源码并标记；文献库缺失、重复键、解析错误或无效 CSL 提供定位信息。存在未解决错误时阻止文献导出，避免静默生成错误文稿。

后续再考虑：裸 `@key` 叙述式引用、`[-@key]`、复杂前后缀、`nocite`、自定义列表位置、`\cite{}` 等 LaTeX 命令别名、`.bst`、Zotero 在线连接及 DOCX/LaTeX 导出。

## 技术设计

### 引用键与标题补全（首版必需）

- 触发：输入 `[@`、在现有引用的 `@` 后继续输入，或在多篇引用中输入 `; @`，打开当前位置的候选列表。光标离开引用范围或按 Esc 时关闭。
- 引用键查询示例：输入 `[@vasw`，匹配 `vaswani2017`，确认后得到 `[@vaswani2017]`。
- 标题查询示例：输入 `[@Attention Is All`，按标题 `Attention Is All You Need` 找到同一条目，确认后同样得到 `[@vaswani2017]`。中文标题也支持片段查询。标题是搜索条件，最终保存的是原始引用键。
- 同时搜索引用键与标题，无需用户切换搜索类型；保留作者、年份作为辅助搜索字段。排序优先完整引用键、引用键前缀、标题连续匹配、标题多词匹配，然后是其他模糊匹配，结果顺序保持稳定。
- 搜索不区分英文字母大小写，并统一 Unicode 和连续空白；标题搜索使用解析后的可读文本，处理常见 BibTeX 花括号保护及 LaTeX 字符转义。插入时保留引用键原始大小写。
- 候选项以标题为主要信息，同时展示引用键、作者、年份；同名标题可凭引用键及作者年份区分。缺少标题时以引用键为主要信息。
- 支持方向键选择、Enter 或 Tab 确认、Esc 关闭及鼠标选择；无候选时不接管 Enter/Tab。中文输入法组合输入期间不接管确认键，组合结束后更新查询。
- 替换只作用于光标所在引用项的查询文本；保留同组其他引用、现有页码、正文及括号，已有右括号时不重复添加。整个补全插入作为一次可撤销操作。
- 从当前文档配置的本地文献库建立搜索索引，缓存候选数据并限制显示数量；切换文档或刷新库后更新索引。没有配置文献库、库未加载或查询无匹配时显示相应提示。
- 在 Muya 行内编辑和 CodeMirror 源码模式分别接入补全界面与光标定位，但复用查询、上下文识别和文本替换逻辑。代码、公式、转义文本及链接目标中不触发引用补全。

### 数据与排版

- 按需引入 `@citation-js/core`、`@citation-js/plugin-bibtex`，将文献转换为 CSL-JSON；使用 `citeproc`（citeproc-js）处理文内引用和列表。
- 用文档级引擎按完整引用顺序处理 citation clusters，接收会影响早先引用的消歧结果，再生成 bibliography。避免逐条独立格式化造成编号或消歧不一致。
- 建立统一引用模型：原始语法、引用键/页码、源码范围、稳定 occurrence ID；统一输出文内 HTML、列表 HTML、条目锚点和诊断。
- 缓存文献解析和样式；正文编辑采用防抖。文档、文献库或样式改变时计算新结果，并清理相关 token/render 缓存。
- 异步请求绑定文档 ID 和版本号，切换标签或销毁编辑器后丢弃过期结果。缓存按文档隔离。
- 包含样式、locale 及相应来源/许可证；锁定依赖版本。先验证依赖在当前 Vite/Electron 中的构建兼容性、键映射和解析行为。

### 编辑与导出

- 在 `packages/muyajs/lib/parser/index.js` / `rules.js` 的编辑 tokenizer 和 `parser/marked/inlineLexer.js` 的导出 lexer 中接入同一个引用语法解析函数；在普通链接和文本规则吞掉语法前识别，并尊重代码、数学、转义的优先级。
- 新增行内 citation renderer，保留源码范围与光标映射；通过显示节点呈现生成内容，不改变文档中的原始字符串。
- 自动参考文献列表作为独立只读视图，由编辑器组件管理，位于可编辑正文容器之外。提供锚点跳转，不让渲染结果触发文档修改。
- 在 `exportHtml.js` 接入统一结果；导出等待当前文档和引用库处理完成，再进入已有公式、图表、主题与打印流程。
- 对启用文献引用的文档，导出时消费 YAML 配置，不把配置显示成正文；未启用文献引用的文档沿用原行为。
- 生成 HTML 通过已有 DOMPurify 流程；ID 编码并保证重复引用锚点唯一。

### 桌面集成

- 在 `editor.vue` 接入文档配置、加载/刷新、插入选择器、只读列表及导出等待。
- 通过主进程和 preload 读取本地文献/样式，复用可用的文件接口或补充有类型的引用专用接口。渲染进程不直接访问文件系统。
- 使用成熟 YAML 解析器读取和更新配置，不用正则表达式代替 YAML 解析。写入 front matter 时保留未知字段及可保留的注释；无有效 YAML 时提示修正，不覆盖用户配置。保存与另存为后重新解析相对路径。
- 仅加载所需本地数据和内置资源，不自动访问 DOI 服务或下载 CSL。
- 新增英文/中文文案及使用文档。无需升级或切换 `packages/muya` 编辑器。

## 实施顺序

1. **依赖和核心模型**：验证解析库、引用键、CSL 和打包，建立共享模型及真实文献样例。
2. **配置和文件加载**：YAML 配置、相对路径、诊断、刷新、文档隔离及设置入口。
3. **编辑体验**：语法识别、光标映射、引用键/标题补全（普通与源码模式）、跳转和只读参考文献列表。
4. **导出闭环**：统一 HTML/PDF/打印输出及错误处理。
5. **验收与交付**：相关单元及桌面端到端测试、类型检查、lint、构建、使用文档与人工检查。

实施按上述顺序推进，但交付以编辑和导出闭环为准，不能仅完成导出就认定功能完成。

## 验收条件

- 单篇、多篇、页码、重复引用的显示与源文件往返正确；保存、重新打开、源码切换后键和语法保留。
- 插入或删除前面的引用后，IEEE 自动重新编号；APA 同作者同年消歧同步更新；编辑器和 HTML/PDF/打印一致。
- 中文作者/标题、Unicode 路径、含空格路径、多库及常见 BibTeX 转义能够处理；无法处理的输入明确诊断。
- 行内代码、代码块、数学公式、邮箱、链接和脚注/引用式链接不受误识别影响。
- 标签切换、另存为、文献库刷新及异步旧响应不会串用数据或改变正文；候选插入支持撤销/重做。
- 引用键前缀、英文标题片段、多词标题及中文标题均能命中对应候选；不同查询方式选中同一文献后插入相同的原始引用键，标题不写入引用语法。
- 候选同时显示标题和引用键，支持键盘与鼠标确认；中文输入法不被打断；多篇引用中的补全仅替换当前项，保留其他引用与页码、不重复闭合括号，撤销一次恢复补全前文本。
- 普通编辑模式和源码模式均通过上述补全验收；文献库刷新后候选同步更新，未配置库、加载中、加载失败和无匹配均有明确提示。
- 缺失库、错误 YAML、重复键、缺失引用键及无效样式有可操作的提示；导出不会使用过期或不完整结果。
- 使用包含 1,000 条文献、200 个引用的样例检查编辑响应；仅加载文献库或更新引用显示不产生“文档已修改”。
- 相关测试、类型检查、lint 和桌面构建通过；验证现有脚注、链接、公式和导出回归。

## 审阅要点

建议批准的首版是：**`[@key]` 语法、本地 `.bib`、IEEE/APA 与本地独立 CSL、文内实时显示、文末自动列表、引用键和标题补全（普通与源码模式）、HTML/PDF/打印一致**。

已按用户认可的范围实施；`\cite{key}` 原生 LaTeX 写法、`.bst` 及其他明确列为后续的能力不属于本次交付。
