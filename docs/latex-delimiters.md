# LaTeX 数学公式分隔符

行内公式使用 `\(...\)`：

```markdown
表达式 \(F_A = F_B\) 放在段落中。
```

独立公式使用 `\[...\]`，分隔符单独成行：

```markdown
\[
\sum_{i=1}^{n} x_i
\]
```

也支持单行独立公式：

```markdown
\[x^2+y^2=z^2\]
```

两种格式使用与已有数学公式相同的 KaTeX 渲染器和数学宏设置。源码模式提供 LaTeX 高亮；保存保留括号分隔符，不自动替换为 `$`。代码块、行内代码、转义后的起始分隔符和未闭合的表达式不会被当作完整公式。

在普通编辑模式中，单独输入 `\[` 后按 Enter，可进入独立公式编辑框；框内编辑公式内容即可，结束分隔符在保存时生成。原有 `$...$`、`$$...$$` 和 GitLab 数学代码块仍可使用。
